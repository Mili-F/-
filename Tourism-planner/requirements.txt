# ============================
# 智游AI - 环境配置说明
# ============================
#
# 一、Python依赖安装
# ============================
# 安装命令：
# pip install -r requirements.txt
#

fastapi
uvicorn
python-dotenv
pydantic
dashscope
httpx


# ============================
# 二、环境变量配置
# ============================
#
# 在项目根目录创建 .env 文件，配置以下内容：
#
# DASHSCOPE_API_KEY=你的阿里云通义千问API密钥
# AMAP_KEY=你的高德地图POI搜索API密钥
#
#
# 三、启动服务
# ============================
#
# 启动后端API服务：
# python API_main.py
#
# 服务地址：
# - API服务：http://localhost:8000
# - API文档：http://localhost:8000/docs
#
# 前端使用：
# 直接用浏览器打开 index ().html 文件即可
#
#
# 四、注意事项
# ============================
#
# 1. 确保 .env 文件在项目根目录
# 2. API密钥不要提交到代码仓库
# 3. 高德地图Web服务Key需要单独申请
# 4. 首次运行需要先安装Python依赖
